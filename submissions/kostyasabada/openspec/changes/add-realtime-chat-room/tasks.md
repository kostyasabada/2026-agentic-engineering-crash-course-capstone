# Tasks

Rules for every task below (from `docs/review-process.md`): the main agent only coordinates. Each task gets a fresh maker subagent with a scoped handoff (task ID `add-realtime-chat-room-<group>-<n>`, e.g. `add-realtime-chat-room-2-1`, acceptance criteria, spec/design paths, owned files, required checks) and no full history; a separate checker (a Claude Code subagent) reviews the frozen snapshot and reruns the checks. Evidence goes to `docs/evidence/<task-id>/` (`implementation.md`, `checks.txt` with actual commands, outputs, exit codes, date, and `node --version`, `snapshot.txt`, `review.md`). Findings return to the same maker. A checkbox is ticked only after the checker accepts the final snapshot. Tests are written red-first where practical: record the failing run before the implementation makes it pass. An optional extra review by Codex/ChatGPT may be added to a task's evidence only when it was actually performed; it is not a completion gate.
